TRANSFEROPS – VEHÍCULO FIJO POR CHOFER

1. Abre index.html.
2. En Vehículos, crea las unidades (modelo, placa y capacidad).
3. En Choferes, selecciona el vehículo fijo en cada ficha.
4. En Mesa o Despacho, elige únicamente el chofer: su vehículo y placa se incorporan automáticamente.
5. Si el chofer no tiene vehículo o no alcanza la capacidad, el sistema bloquea la asignación.
6. Al cambiar el vehículo fijo de un chofer se actualizan sus servicios existentes.
7. Los 50 servicios ficticios se mantienen disponibles con el botón Cargar 50 reservas de prueba.

Los datos se almacenan localmente en el navegador. Antes de subir una nueva versión a GitHub Pages haz una copia JSON de tus reservas. No es un software multiusuario o con base de datos central.
